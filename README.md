# Офисный котик для Ани

Готовое приложение для Windows, собранное из одного файла Python. Нужен только GitHub и браузер: устанавливать Python на компьютер не нужно.

## Сборка на GitHub

1. Создайте репозиторий на https://github.com/new, например `CatHelper-Anya` (Public или Private).
2. Загрузите `main.py`, `requirements.txt` в корень репозитория. Для файла workflow нажмите **Add file → Create new file**, в поле имени вставьте `.github/workflows/build.yml`, а в редактор — содержимое одноименного файла из проекта. Сохраните изменения в ветку `main`.
3. Откройте вкладку **Actions** → **Build Windows EXE** → **Run workflow** → **Run workflow**. При загрузке файлов сборка также запускается автоматически.
4. Откройте завершенный запуск (зелёная галочка). Внизу страницы, в разделе **Artifacts**, скачайте `CatHelper_Anya_Windows`.
5. Распакуйте ZIP. Внутри — `CatHelper_Anya.exe`. Запустите его двойным кликом.

## Управление

- Круглая кнопка в правом верхнем углу сворачивает/разворачивает офис. Правый клик по кнопке открывает меню.
- Правый клик по котику → настройки. Левый клик → погладить.
- Меню рядом с часами Windows (область уведомлений) позволяет покормить котика, изменить статус заявок, открыть настройки и полностью выйти.
- Компьютер на столе включается/выключается по клику, когда офис открыт.
- Настройки: окрас, глаза, полнота, времена года, три звонка, нижняя панель, автозапуск Windows.
- Настройки хранятся в `%APPDATA%\CatHelper_Anya\settings.json` (рядом с EXE ничего создавать не требуется).

## Важные особенности

- `CatHelper_Anya.exe` — **переносимый EXE**, а не установщик с мастером установки. Python на ПК не нужен.
- Офис можно быстро скрыть, оставив только котика и панель. Настоящее встраивание за значки рабочего стола Windows специально не используется, поскольку оно зависит от внутреннего устройства Explorer и может работать нестабильно.
- Нижняя панель пропускает клики сквозь себя. Котик перехватывает клики только в области своего силуэта, чтобы его можно было погладить.
- Системный сигнал используется вместо внешнего звукового файла: воспроизведение настоящего аудио-мурлыканья без файлов не предусмотрено.
- Три уведомления Авито появляются в выбранные минуты, **если приложение запущено**. Уже прошедшие времена при запуске не воспроизводятся задним числом. При выключенном ПК сообщения не показываются.
- API погоды: Open-Meteo, без ключа. Время и дата берутся из локальных часов Windows. Для времени Омска установите соответствующий часовой пояс Windows.
- При первом запуске каждого дня появляется вопрос о заявках. Если ответить «Ещё нет», напоминания повторяются с интервалом около 90 минут в рабочее дневное время.
- GitHub Actions загружает готовый EXE как артефакт в ZIP; его нужно распаковать перед запуском.
